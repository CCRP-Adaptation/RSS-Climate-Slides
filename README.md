This repository was developed to automate the production of climate slides used in presentations like RSSs and SP engagements.

It pulls from the 2024 Climate Future Summaries folders, reads in data and figures, then uses a Quarto markdown to produce PowerPoint slides of the most common climate variables we report on.

Revisions still need to be made but production has halted as 9/26/2025.
